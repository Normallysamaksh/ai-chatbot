# AI Chatbot with Amazon Bedrock Knowledge Bases

A RAG chatbot: upload a document, ask questions about it in plain English. 
Retrieval runs through Amazon Bedrock Knowledge Bases, and 
Meta Llama 3 (also on Bedrock) generates the answers.

---

## Features
- Upload PDF documents
- Documents get ingested into a Bedrock Knowledge Base automatically
- Semantic search via AWS-managed vector retrieval
- Answers generated by Meta Llama 3
- FastAPI backend, Streamlit frontend
- Runs in Docker, deploys to EC2
- IAM role authentication — no hardcoded credentials

---

## How It Works

A user uploads a PDF, which lands in S3. Bedrock Knowledge Base indexes it. 
When the user asks a question, the app pulls the relevant chunks back out 
and hands them to Llama 3, which generates a response grounded in that context. 
The answer comes back through the Streamlit UI.

## Running Locally

### Clone
```bash
git clone https://github.com/Normallysamaksh/ai-chatbot.git
cd ai-chatbot
```

### Install
```bash
pip install -r requirements.txt
```

### Configure AWS
Attach an IAM role (recommended) or set up AWS CLI credentials. You'll need access to:
- Amazon Bedrock
- Amazon Bedrock Knowledge Bases
- Amazon S3

### Start Backend
```bash
uvicorn backend.main:app --reload
```

### Start Frontend
```bash
streamlit run frontend/app.py
```

## What I Learned Building This

I swapped a self-managed Chroma vector store for Bedrock Knowledge Bases, 
which meant rethinking how retrieval and ingestion worked end to end rather than 
just changing a config value. The rest came together around that: a FastAPI 
backend to serve it, Docker to package it, and an IAM role on EC2 so nothing 
needed a hardcoded key.
